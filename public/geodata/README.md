Geodata used by HellFire for local visualization:

- `countries.geo.json`: country outline geometry for public conflict country borders.
- `ukraine-oblasts.geo.json`: trimmed OpenStreetMap-derived Ukraine oblast boundaries from `github.com/EugeneBorshch/ukraine_geojson`, rounded and property-stripped for local civil context overlays.

These files are rendered as approximate public situation context only. They are not used for tactical frontlines, targeting, or troop tracking.
